# Kochi Metro Rail Lines Application Design

A UI/UX prototype designed for internal Smart India Hackathon participation focused on improving metro navigation, ticket booking, live tracking, passenger management, and operational monitoring systems for Kochi Metro Rail Limited (KMRL).

## Features
- Ticket booking system
- QR-based live ticket generation
- Metro route overview
- User dashboard
- Passenger analytics
- Smart alerts and notifications
- Admin monitoring dashboard
- Operational controls panel

## Tools Used
- Figma
- UI/UX Prototyping
- User Flow Design
